PORT OF DUQM — VENDOR AND TENDER USER GUIDE
Edition 1 | 5 October 2026

FILES FOR THE TEAM
1. PORT_OF_DUQM_VENDOR_TENDER_USER_GUIDE.pdf — illustrated guide with clickable contents/bookmarks.
2. PORT_OF_DUQM_VENDOR_TENDER_USER_GUIDE.docx — editable Word version of the same 71 procedures.
3. START_HERE.html — searchable offline guide; click an image to enlarge it.
4. TEST_CHECKLIST.csv — open in Excel and complete one row per guide procedure.
5. ISSUE_REPORT_TEMPLATE.txt — copy for each problem found.
6. images/ — 94 captured screens/forms and the logo. Keep this folder beside the HTML.
7. sample-documents/ — sample opening record and regret letter PDFs.
8. SCREENSHOT_INDEX.json and SHA256SUMS.txt — reference inventory and file checksums.

HOW TO USE
Extract the whole ZIP into a folder before opening START_HERE.html.
Give the team the PDF and checklist, or the complete ZIP for offline use.
Assign separate test users for each role. Use your organisation's approved test
portal and authorised test payment process. Use unique vendor CRs and tender
references. The guide does not contain test account passwords or provider keys.

SCOPE
Vendor group/fees/documents, registration and waiver review, company profile,
contacts and CR access, updates/renewal/accounting, department tender requests,
all six tender setup steps, dates and manager-approved changes, audience filters,
publication, participation/payment, bids, clarifications/attachments, three-key
opening, signatures, printing, procurement handover, evaluations, award/regret,
delivery statuses, cancellation/retender/stage reopening, audit and troubleshooting.
Gate pass and PTW are outside this guide.

NOTES
Screenshots are from an isolated local application copy using sample data.
They illustrate individual states, not one continuous chronological live test.
Fees, dates, document requirements and assignments in production can differ.
Email and SMS delivery were disabled in the screenshot copy. No bank-hosted
payment screenshots or real delivery proof are claimed.
This bundle is documentation only. Do not upload it as an application patch or
run database updates from it. Word pagination may differ; the listed PDF page
references refer to the PDF edition.
